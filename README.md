# فزعة | Fazaa — النسخة الأولى (موقع PWA)

موقع بدون أي بناء (build). HTML + CSS + JavaScript عادي. البيانات تنحفظ على جهاز المستخدم (localStorage).

## تشغيل محلي

```bash
cd fazaa
python3 -m http.server 8000
# افتح http://localhost:8000
```

> لازم تشغّله من سيرفر (مو بفتح الملف مباشرة) حتى يشتغل الـ Service Worker وتحديد الموقع (GPS).

## النشر على Netlify

1. ادخل https://app.netlify.com/drop
2. اسحب مجلد `fazaa` (أو ملف الـ zip) وأفلته.
3. تحصل رابط https جاهز. الـ GPS والتثبيت كتطبيق يحتاجون https.

## شنو شغّال

- دخول: الاسم الثلاثي + رقم الهاتف (07xxxxxxxxx) + نوع السيارة + موافقة الخصوصية
- الرئيسية: خريطة (Leaflet/OpenStreetMap)، أقرب كرين متاح، قائمة بالمسافة، فلتر (متاح/النوع)، موقع GPS أو يدوي
- اتصال بضغطة (`tel:`) مع تسجيل كل اتصال
- وضع السائق: تسجيل الكرين، متاح/مشغول، تحديث الموقع وأنت «متاح» والتطبيق مفتوح، إحصائيات
- الباقات (تجريبية بدون دفع)
- حسابي: سجل اتصالاتي، تنزيل بياناتي، حذف الحساب
- لوحة الإدارة (رمز PIN): إضافة/حذف/توثيق كرينات، نشاط، تصدير JSON/CSV

## حدود هذي النسخة (مهمة)

- **ما كو مزامنة بين الأجهزة.** كل جهاز يشوف بياناته فقط. الكرينات اللي يسجّلها سائق بجهازه ما تظهر لزبون على جهاز ثاني.
  لهذا الكرينات الموجودة هسه **تجريبية** (شارة «تجريبي») والاتصال بيها ما يطلّع رقم حقيقي.
  الحل الحقيقي: Supabase (المرحلة 3 بالوثيقة).
- لوحة الإدارة محمية بـ PIN محلي فقط، مو أمان حقيقي.
- موقع السائق يتحدّث فقط والتطبيق مفتوح؛ المتصفح ما يرسل موقع بالخلفية.
- Leaflet والخط (Cairo) يتحمّلون من CDN أول مرة، وبعدها الـ Service Worker يخزّنهم.
- بلاطات خريطة OpenStreetMap المجانية مناسبة للتجربة؛ لاحقاً استخدم مزوّد خرائط بخطة تجارية.
